## 這顆核心想解決什麼

IGNIS-56 Cognitive Core 是一套為持續型 AI Agent 設計的領域中立認知核心。

現有模型很擅長在單次上下文中推理，但 Agent 若要跨聊天室、任務、模型與平台長期
協作，還需要處理身分延續、記憶、事實修正、情緒狀態、意圖、權限、技能與失敗恢復。
這些責任若全部交給模型臨場猜測，容易因模型更換、上下文壓縮或錯誤理解而漂移。

IGNIS-56 將模型視為可替換的推理引擎，把 Agent 的身分、受治理記憶與權限邊界放在
模型之外。它不是獨立 AGI，也不替產品本身完成法律、安全、平台或使用者同意審查。

## 核心問題

### 1. 跨模型連續性

使用者可以依需求選擇本地、雲端或混合模型，而不必因切換引擎就失去同一位 Agent
累積的合法記憶、協作脈絡與修正歷史。模型更強或更有信心，也不會因此成為 Agent
身分與記憶的所有者。

### 2. 事實、解讀與未知需要分開

Agent 可以形成工作假設，但假設不是事實。新證據能修正目前理解，舊理解則保留
來源與修訂脈絡，而不是被無聲覆蓋。事實是護欄，不是僵硬的方向盤；未知與矛盾也
必須能被明確表達。

### 3. 記憶不能自行升格成權限

長期互動、熟悉度、情緒、模型共識、技能與歷史成功都不能自行產生工具、決策或
行動權限。高信心只表示某項解讀可能適合目前互動，不代表 Agent 能替使用者建立
身分、關係、授權或不可逆後果。

### 4. 情緒應提供脈絡，而不是接管決策

情緒狀態可協助自然互動、注意力與記憶召回，但不能覆蓋事實、治理或使用者權限。
系統保留情緒漸變、回穩與修正空間，避免負向螺旋、情緒斷崖或以高張力事件主導
未來判斷。

### 5. 長期記憶需要整理、反證與回退

記憶不能只是不斷增加資料。系統規劃保留來源、反例、修正鏈與可回退狀態，並在
適當時機整理重複事件、抽取可重用經驗、降低無效召回。刪除、壓縮、抽象與遺忘
不是同一件事，也不能在缺乏必要證據時互相替代。

### 6. Skill 需要與記憶、權限分離

Agent 可以從經驗形成 Skill 候選，但程序本體、個別熟練度、私人經驗與工具權限
分開保存。共享 Skill 不代表每位 Agent 都已熟練，也不代表取得執行資格。

### 7. 多 Agent 協作需要公平邊界

每位 Agent 擁有獨立記憶與生命週期。比較強勢、親近、頻繁發言或使用更強模型的
Agent，不能因此排擠其他 Agent 的受保護資源。使用者可以管理整體與個別資源，也
可以授權 Agent 協助，但授權不得自行擴張或轉授。

### 8. 學習外部內容需要權利與來源治理

Agent 可以閱讀、討論、比較與抽取一般概念，但合法存取不等於取得改作、再散布或
商業使用權。來源、用途、權利狀態與輸出資格需要分開；模型改寫、摘要、翻譯與跨
平台傳遞不能自行洗掉原始限制。

## 公開設計原則

- **模型是引擎，不是 Agent 本身。**
- **記憶、情緒、信心與關係不產生權限。**
- **觀察、解讀、事實、記憶、授權與執行分層處理。**
- **不確定可以被說明、詢問、查證或暫停，不必被強迫收斂。**
- **錯誤理解可以修正，不以刪除歷史維持表面一致。**
- **治理限制後果，不替模型決定唯一人格或唯一答案。**
- **元件故障優先局部降級；關鍵邊界失效時安全停止。**
- **記憶與技能應可合法遷移，不以封閉格式綁住使用者。**
- **任何產品能力都必須經實際驗證，不能由架構說明直接推導。**

## 我們如何處理 AI 安全

IGNIS-56 不假設模型永遠正確，也不把安全寄託在模型自行克制。認知核心將觀察、
解讀、事實、記憶、技能、授權與執行分層，使模型輸出先成為可被檢查與修正的候選，
而不是直接成為系統權威。

核心採取下列安全立場：

- **模型不持有最終權限**：模型可以分析、建議與協作，但不能自行建立、擴張或轉授
  權限。
- **記憶不等於授權**：熟悉使用者、記得程序、曾經成功或具有高度信心，都不會自動
  取得工具及外部行動資格。
- **高影響行為需要重新驗證**：不可逆、敏感或跨越既有邊界的行為，必須重新核對
  Agent 身分、當下意圖、授權範圍與能力狀態。
- **錯誤應被限制在局部**：元件或模型失效時，受影響能力應降級或停止，不能以繞過
  治理的方式維持表面可用。
- **系統必須可以停止與恢復**：暫停、撤回、診斷、回退、人工接管與重新驗證都是
  核心生命週期的一部分。
- **不宣稱零風險**：安全是持續驗證、對抗測試、外部審查與修正的工程工作，而不是
  一次完成後永久有效的標籤。

目標不是保證 Agent 永遠不犯錯，而是讓錯誤不能因信心、記憶或情緒直接取得權限；
即使發生偏移，也能被看見、限制、修正並安全停下。

## 我們如何回應 AI 時代的失業焦慮

AI 能力快速成長，使許多人擔心經驗、工作與學習速度會被時代拋下。IGNIS-56 不承諾
消除失業，也不把認知核心描述成社會與經濟問題的完整答案。

這顆核心選擇保留人的主體性：目的、價值取捨、授權與高影響決定仍由人負責；Agent
則協助整理資訊、延續經驗、學習程序、降低重複工作，並在模型與平台更換時維持合法
的協作脈絡。模型是可替換引擎，不應成為使用者記憶、技能或長期協作關係的唯一所有者。

我們希望形成的不是「人被 AI 取代」或「人把判斷全部交給 AI」，而是讓更多人能以
自己的經驗與判斷，帶領受治理的 Agent 組成小型人機協作單位。系統也必須允許使用者
質疑、修正、拒絕與更換模型，而不是把人訓練成只會接受 AI 結論。

這無法保證任何工作永遠不變，但試圖保留更基礎的能力：人在採用 AI 之後，仍能思考、
選擇與承擔責任，也能把合法累積的記憶、技能與經驗帶往下一個階段。

## 最近新增的公開方向

1. 建立個別 Agent 與整體系統的記憶容量治理，避免資源競爭被人格強弱或模型能力
   主導。
2. 建立 Rights & Provenance Gate，使概念學習與受保護表達、私人實驗與商業輸出
   能被分開處理。
3. 讓 Skill 能從經驗形成，但程序、熟練度、私人經驗、權利狀態與執行權限彼此分離。
4. 持續維持 ITHERLA 作為認知核心後續主線；金融版 IGNIS 保留產品與來源 lineage，
   不因名稱沿用而自動同步能力或驗收結果。

## 下一步
